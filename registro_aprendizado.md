# Ficha de Registro de Aprendizado

Preencher uma ficha por ciclo de teste. Guardar o histórico para alimentar a inteligência do canal.

**Ciclo n.º:** ___  **Período:** ___ a ___

| Tópico | Preenchimento |
|---|---|
| **[Hipótese Testada]** | |
| **[Resultado vs Baseline]** | Média: ___% vs baseline ___% (variação: ___%). Decisão: confirmada / invalidada / inconclusiva. |
| **[Aprendizado Comportamental Extraído]** | |
| **[Próxima Ação]** | |

## Verificações antes de fechar o ciclo

- [ ] Todas as peças atingiram o mínimo de impressões?
- [ ] Alguma variável de distorção contaminou a leitura (sazonalidade, alcance atípico)?
- [ ] A decisão seguiu a régua fixada antes da publicação?
- [ ] O novo baseline foi atualizado?

---

## Exemplo (ciclo 1, dados fictícios)

| Tópico | Preenchimento |
|---|---|
| **[Hipótese Testada]** | Se o CTA do último slide oferecer um checklist por comentário, a Taxa de Intenção sobe. |
| **[Resultado vs Baseline]** | A preencher após os 3 carrosséis. Baseline: 0,8%. |
| **[Aprendizado Comportamental Extraído]** | A preencher. |
| **[Próxima Ação]** | Se confirmada: testar o gancho do slide 1. Se refutada: testar a oferta do CTA. |
